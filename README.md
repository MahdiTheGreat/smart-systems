# Smart Systems Monorepo

This monorepo consolidates related smart systems, IoT, and embedded projects while preserving full Git commit history.

## Subprojects
- **attendanceCheck**: Smart attendance check system
- **smartScreen**: Smart display / screen system
- **smartWasteBin**: Smart waste management and bin monitoring
- **smartFarming**: Automated smart farming and agricultural monitoring
- **smartParking**: IoT parking vacancy and tracking system
- **MicroprocessorProjects**: Embedded microprocessor code and labs
- **assembelyCodes**: Assembly language programs and low-level routines
